Global Cataclysm 1972

A grand strategy game of the world at war in 1972: buy armies, fleets and air wings, make and break alliances, and force your rivals to surrender.

Download for Windows

  1. Unzip GlobalCataclysm.zip anywhere and run GlobalCataclysm.exe.
  2. Windows may warn that it's from an unknown publisher: choose More info, then Run anyway.
  3. Register a player name, then join a game with its code or start your own.

When the game says a new version is out, download it again from this page. The game connects to GC_DOMAIN.
